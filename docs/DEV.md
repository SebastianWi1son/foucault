## 1. 数学核心体量评估

**数学内核 ~550~800 行（header-only C++）；整个 core（数学+模型+量测+求解器+门面）~1500~2300 行。** 几个工作日的体量。

| 模块 | 内容 | 估算行数 |
|---|---|---|
| `vec3.h` | 加减乘除、点积、叉积、模长、归一化 | 80~120 |
| `quat.h` | 单位四元数、乘法、共轭、归一化、旋转向量、欧拉角互转、**陀螺积分**（`q̇=½Ωq`；名义一阶欧拉，量化后实测全局二阶） | 180~260 |
| `mat.h` | **定长矩阵模板**（3×3 / 6×6 / 3×6…）：乘/加/减/转置/求逆（Gauss-Jordan）/单位阵 | 250~350 |
| `scalar_ops.h` | `invSqrt`、clamp、弧度/度、sqrt/atan2 钩子 | 40~60 |
| model/ | 状态表示（q+bias / ψ）、2D/3D 运动学积分（if constexpr 裁剪） | 120~180 |
| measure/ | 加速度计/磁力计/外部 yaw 观测 + 仲裁 | 150~250 |
| solver/ | 增益接口 + Mahony + Madgwick + EKF（卡方/渐消/限幅）+ 1D-KF | 500~800 |
| estimator.h + config.h + output.h | 门面、profile、品质输出 | 150~250 |

**为什么这么小**：EKF 状态维度写死（6×6、3×6、3×3），每个矩阵运算手写专用函数，不上通用矩阵库（Eigen 是 10 万+ 行）。这就是"定长模板 + 专用实现"路线的价值。

**H7 性能预期**（数学核心不是风险项）：Mahony ~1.3µs、EKF ~29µs（参考实测 H723 @550MHz）。FPU 全开 + 可选 CMSIS-DSP 钩子（sqrtf/atan2f 即可，矩阵手写不必上 arm_mat_*）。**算力无风险，正确性和调参才是风险。**

## 2. 理论学习路径（实现级理论，3~5 天，边做边学）

### 2.1 必须理解的三个概念（不学透抄对也调不了）

| # | 概念 | 不理解的后果 |
|---|---|---|
| 1 | **四元数代数与运动学**：乘法、旋转、归一化、`q̇=½Ω(ω)q` | 读不懂参考库任何一行；陀螺积分写错方向/顺序 |
| 2 | **观测器结构**：预测 + 残差 × 增益（`z−h(q̂)` = 实测重力方向 vs 预测重力方向的夹角） | 姿态漂了不知道查哪里；分不清"积分错还是修正错" |

### 2.4 提醒

**不要"先学完再动手"** —— 理论无限深（李群、随机微分方程、可观测性分析），项目只需要三条公式。节奏：读懂 Solà 前两章 → 立刻实现 Mahony → 数据验证 → 带问题学 EKF。

### 2.5 学习关键词清单（带验收标准）

> 按 Level 顺序学；每个关键词要求：能用自己的话解释 + 对照参考库能找到对应代码。
> 验收标准达成才算过关，全部过关再回来开工。

**Level 1 · 四元数与姿态运动学（动手前必学）**

| 关键词 | 要搞懂什么 | 验收标准 |
|---|---|---|
| 四元数定义 | q=(q0,q1,q2,q3)、单位模长、共轭、逆 | 能解释 q 与 旋转轴/角 的关系 |
| 四元数乘法 | Hamilton 积（非交换） | 能心算两个四元数相乘的 16 项展开（或至少写出公式） |
| 旋转公式 | v′ = q⊗v⊗q*（旋转向量） | 能解释为什么两侧都要乘 |
| 欧拉角互转 | 四元数 ↔ 欧拉角（atan2/asin 公式） | 能解释万向锁是什么、四元数为什么没有 |
| 归一化 | ‖q‖=1 约束 | 能解释为什么积分后必须重新归一化 |
| **姿态运动学** | **q̇ = ½·q⊗ω（四元数微分方程）** | **能徒手写出 Ω(ω) 矩阵（参考库 F 矩阵左上 4×4 对照）** |
| 离散积分 | q(t+dt) = q + q̇·dt（名义一阶欧拉 = 一阶毕卡 = RK1）；精确指数积分（进阶） | 能解释 dt 大小对积分误差的影响。**注意**：现实现末尾归一化会消掉二阶项，实测全局二阶（p≈2.0，见 `test_math_audit` F3），故当前精度瓶颈不在积分阶数 |
| 叉积/点积几何意义 | a×b 的大小=夹角、方向=法向 | 能解释叉积为什么能当"误差角"用 |
| 参考系 | body frame vs world frame（NED） | 能解释陀螺角速度是哪个系里的 |

**Level 2 · 观测器结构与 Mahony（实现 Mahony 前必学）**

| 关键词 | 要搞懂什么 | 验收标准 |
|---|---|---|
| 互补滤波 | 高通陀螺 + 低通加速度计，频率域拼接 | 能画出框图；能解释 α 的物理含义 |
| 观测器结构 | 预测 + 残差×增益 的反馈回路 | 能说出"残差 z−h(q̂) 是什么的差" |
| 重力作为参考 | 静止时加速度计测重力方向；归一化 | 能解释为什么运动时加速度计不可信 |
| **叉积误差** | err = a_meas × a_pred（小角度近似） | 能证明：夹角很小时 ‖a×â‖≈夹角 |
| PI 控制器 | Kp 比例项（拉回）、Ki 积分项（消零偏） | 能解释为什么 Ki 能消除陀螺零偏、为什么 Ki 太大会发散 |
| 增益的物理含义 | Kp 大→信量测（抖动）；Kp 小→信陀螺（滞后） | 能预测：Kp 调大后静态噪声变大还是变小 |
| 陀螺零偏/漂移 | bias 定义、温度漂移 | 能解释为什么纯积分几分钟就飘 |
| yaw 不可观测性 | 重力矢量与 yaw 旋转轴平行 | 能解释为什么 6 轴 IMU 无法得到绝对航向 |

**Level 3 · 状态空间与 EKF（移植 EKF 前必学）**

| 关键词 | 要搞懂什么 | 验收标准 |
|---|---|---|
| 状态空间模型 | x（状态）、f（过程模型）、h（观测模型） | 能给本项目写出 x=[q,b]，f、h 各是什么 |
| **卡尔曼五步** | 预测/协方差传播/增益 K/更新/协方差更新 | 能写出 K = P⁻Hᵀ(HP⁻Hᵀ+R)⁻¹ 并解释每一项 |
| P/Q/R 物理含义 | 协方差 P、过程噪声 Q、量测噪声 R | 能预测：Q 调大→更信量测还是更信陀螺 |
| **雅可比/线性化** | F=∂f/∂x、H=∂h/∂x，一阶泰勒展开 | **能对照参考库 F 矩阵右上 4×2 零偏耦合项、H 矩阵 3×4，指出对应哪项偏导** |
| EKF vs KF vs ESKF | 线性/扩展/误差状态的差别 | 能说出 ESKF 为什么数值更稳（误差是小量） |
| 可观测性 | 哪些状态能被量测确定 | 能解释为什么 b_z 不可估（参考库 GyroBias[2]=0） |
| 卡方检验 | innovation 的统计检验，超阈值拒量测 | 能解释为什么能防"运动加速度污染" |
| 渐消因子 λ | 零偏协方差防过收敛 | 能解释为什么零偏估计"收敛死了"不好 |
| Allan 方差 | ARW（角度随机游走）/ bias instability | 能说出它给 Q/R 定初值的思路（跑 gaochq 脚本） |

**Level 4 · 进阶（可选，做 ESKF 或想搞懂理论时再学）**

- 误差状态 EKF（ESKF）：标称状态 + 误差状态，四元数误差用 3 参数小角度（Solà 论文全文）
- SO(3) 李群/李代数：指数映射、伴随（Mahony 2008 理论根基）
- 四元数微分方程精确解：指数积分（现实现已因归一化达到全局二阶，动机是去掉截断误差而非“修漂移”）
- 磁力计校准：椭球拟合、软硬磁（9 轴模式需要）
- 多速率异步融合：不同传感器不同频率的时间戳对齐（量测事件驱动）

**学习方法建议**：
1. 主教材只有一本：Solà 2017（免费 PDF），Level 1-3 覆盖其第 1~3 章；
2. 每个关键词配一道"对照题"：在参考库（CtrBoard QuaternionEKF.c / gaochq ESKF_Attitude.cpp）里找到对应代码行；
3. 维护公式笔记：每学一个公式，记"公式 + 一句话直觉 + 参考库行号"；
4. 中文补充：知乎搜"四元数 姿态解算"入门文，但以 Solà 为准（二手资料常有错）；
5. 学完 Level 1+2 即可回来开工（先做 math + Mahony），Level 3 可以在写 EKF 前一周补上。

| # | 视频/直觉中的说法 | 纠偏结论 | 证据/参照 |
|---|---|---|---|
| 1 | 初始状态就是地球固连坐标系 | 应为：初始 q=[1,0,0,0] = 初始姿态与世界系对齐（旋转 0°） | 参考库 Init 中 xhat_data[0]=1 |

| 5 | 三个方向余弦矩阵共 9 个 | 是一个 3×3 旋转矩阵含 9 个方向余弦（机体 3 轴×世界 3 轴夹角余弦） | 线性代数定义 |
| 7 | 转置 Rzᵀ 获得??坐标系 | Rᵀ=R⁻¹：R 机体→世界，Rᵀ 世界→机体；**代码核心用途：世界系重力经 Rᵀ 转机体系 = 加速度计预测读数（测量模型 h(q)）** | QuaternionEKF.c 的 temp_vector |
| 9 | 万向锁：某几项为 0，姿态不唯一 | pitch=±90° 时第一次/第三次旋转轴重合，3D 退化为 2D，一个姿态 ↔ 无穷多 (yaw,roll)；四元数胜出的真正原因是运动学线性无三角无奇异 | 欧拉角微分方程 vs q̇=½Ωq |
| 10 | 四元数=1实3虚，看不懂怎么表示姿态 | q=(cos(θ/2), sin(θ/2)·n̂)：绕轴 n̂ 转 θ；θ/2 来自旋转公式 v′=qvq* 两侧各乘一次；q 与 −q 同姿态（二重覆盖） | Solà §1-2 |
| 11 | 核心问题变成怎么更好测角速度 | **半对**：预测质量由陀螺决定（✅），但完整问题是融合：陀螺积分（短时准会漂）×向量观测（绝对有噪），Kalman 解决 K 怎么算；地基公式 q̂̇=½Ω(ω)q̂+K·(z−h(q̂)) | 本质公式见 DESIGN.md §1 |
| 12 | 四元数更新式（一阶毕卡）里"没有角度"，不涉及积分 | **错误**：① ω·dt = 增量角 Δθ，Ω(ω)·dt 每一项就是 ½Δθ，式子等价于 qₖ₊₁=qₖ+½Δθ⊗qₖ，每拍注入增量角；② 四元数本身就是累计角度的编码 q=(cos(Θ/2), sin(Θ/2)·n̂)，
Θ=总转角。四元数=角度的编码，不是与角度并列的东西 | 一阶毕卡=一阶欧拉=RK1 |
| 13 | 陀螺原生数据就能求四元数，那要 Mahony/Kalman 干嘛 | 能求，但求出来的是**会漂的**（开环积分，等价于 1D 的 gyro-z 积分）：零偏→误差按 b·t 线性增长，噪声→随机游走。Mahony/Kalman 不是另一种求四元数的方法，而是**给积分加修正项 K·(z−h(q̂)) 的闭环**；加速度计永远测重力方向（绝对参考，与历史无关），残差≠0 就能把姿态拉回 | 参考库实测：roll/pitch 有修正不漂，yaw 无参考照漂（10 分钟 ~10~20°） |

**两个必须补的关键理解**：
- **半角直觉**：四元数编码的是"旋转轴+旋转角"，不是"3虚轴+1实轴"；
- **测量模型 h(q)=R(q)ᵀ·g**：加速度计预测读数 = 世界系重力转到机体系，这是四元数状态与传感器数据之间的桥，也是残差与 H 矩阵的来源。

## 3. 工程规范（模板 §4 落地）

- **零依赖**：仅标准库头文件（core 内无 STL/异常/RTTI/动态内存；host 允许 STL）
- **声明/定义分离**：.hpp/.cpp（数学内核可 header-only 例外）
- **编译告警全开**：`-Wall -Wextra -Werror`；MCU 侧 `-fno-exceptions -fno-rtti -fno-threadsafe-statics`
- **三个独立 CMake target**：`foucault_core` / `foucault_tests` / `foucault_examples`（host/ 工具单独 target）
- **纯函数不持有状态**；有状态组件显式标注（Estimator/Solver/量测仲裁器）；常量/参数聚合进 Config 结构
- **防御**：接口层输入校验（NaN/模长门限/时间倒退），错误语义明确（返回枚举/状态码），不静默吞错
- **构建与测试命令**：桌面 `cmake -B build && cmake --build build && ctest --test-dir build`（命令写入 tests/README）

## 4. 测试守则（模板 §5 落地）

- **锚点测试测行为，不测实现数值**：断言行为不变式（收敛、有界、四元数单位模长守恒、静止时姿态不漂），不是魔法数
- **退出码 = 结果**（0 = 全过）；浮点断言必须容差，禁止 `==`
- **模板/未实例化代码 = 未真正编译**：任何改动必须用 test 实际调用验证（2D 与 3D 实例都要实例化）
- 测试覆盖关键路径 + 边界 + 失败路径（不只 happy path：NaN 输入、dt=0、量测失效降级）
- **改完必回归**：任何改动（含用户敲的代码、注释级改动）必须重新编译 + 全量测试回归
- **数据集回归**（验证策略核心）：NAV1/NAV2/BROAD 回放 + Mahony/EKF/参考库三方对比 + RMSE 报告，作为持续验证手段
