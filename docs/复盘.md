## 错误清单

### [2026-08-30] 数据集坐标系约定未先验证，NAV2 回放 roll 全错
- 现象：首次回放 NAV2 数据集，roll RMSE 179°、pitch 反号（est≈−gt）——看似算法全错。
- 根因：数据集（gaochq 参考库）是世界系 **z-down**（NED 风格）：静止水平时 acc=(0,0,−1)，参考库初始化直接用 `z_state=acc` 可证实；
  本 core 约定世界系 **z-up**（`g_world=(0,0,1)`，静止时 acc 应为 (0,0,+1)）。未做边界适配直接对比。
  佐证：gyro 无需翻转（机体系物理量）、参考库无 deg→rad 转换（gyro 就是 rad/s）、roll/pitch 真值只由重力方向定义，与水平轴无关可直比。
- 修复：回放工具边界处 `acc_adapted = −acc`（core 不动），并在文件头注释数据集坐标系约定。修复后 roll RMSE 2.15°、pitch RMSE 2.65°（MAX ~13°，高动态加速度污染），yaw 漂移 −14.5°/320s（6 轴预期）。
- 教训：**数据集/外部输入的坐标系、单位、列顺序先验证再对比**（外部输入先验证铁律）：先看参考库怎么喂数据、初始化怎么做，再跑数字。
